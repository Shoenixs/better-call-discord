# Участие в разработке

Плагин поставляется одним обычным CommonJS-файлом, который BetterDiscord загружает напрямую. Не добавляй обязательную сборку или сетевые зависимости без необходимости.

Перед pull request запусти `npm run check` и `npm test`. Для изменений воспроизведения добавляй проверки сохранения исходного объекта метода, аргументов, результата и очистки ресурсов. Отдельно отмечай, проводилась ли проверка в настоящем клиенте по [TESTING.md](./TESTING.md).

Не фиксируй webpack ID: ищи модули по проверяемым признакам. Перехваты снимаются в `stop()`, а ошибки пользовательского аудио должны возвращать штатный сигнал.

Вклад должен быть собственным или иметь явно совместимую лицензию с указанным происхождением. Не включай GPL-код, код с неясными правами, извлечённые фрагменты Discord, личные конфигурации или чужие аудиозаписи.
