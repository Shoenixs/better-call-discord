# История версий

## 1.1.0 — 2026-10-31

- Added English and Russian UI, notifications, errors and file dialog text.
- Added a saved language selector: Auto (Discord), English and Russian. Unsupported locales fall back to English.
- Published an English README and a separate Russian README with language links.
- Добавлен выбор языка без сброса мелодии и настроек громкости.
- Added localization tests alongside the audio regression checks.

## 1.0.5 — 2026-10-31

- Сохранён исходный `this` при пропуске обычных сигналов и возврате штатного звонка. Исправляет исчезновение остальных звуков Discord.
- Регрессионные проверки используют непривязанный `original`, как BetterDiscord.
- Подготовлен самостоятельный репозиторий: документация, MIT-лицензия и переносимые тесты без личных аудиофайлов.

## 1.0.4 — 2026-10-30

- Добавлена поддержка текущего `WebAudioSound` с методом `ensureAudio()`.
- Сохранена совместимость с прежним `_ensureAudio()`.
- Добавлена локальная диагностика обнаружения и перехвата звука.
- Получено пользовательское подтверждение своей мелодии и нарастания на реальном входящем звонке.

## 1.0.3 — 2026-10-30

- Исправлено бинарное чтение аудио: файловый API BetterDiscord по умолчанию использовал UTF-8.

## 1.0.2 — 2026-10-30

- Название изменено с GentleRing на Better Call Discord.
- Добавлен перенос прежних настроек.

## 1.0.1 — 2026-10-30

- Вместо отсутствующего `fs.promises` используются методы файлового API BetterDiscord.
- Добавлен поиск скрытого класса звука и ожидание его загрузки.

## 1.0.0 — 2026-10-30

- Первая версия: локальная мелодия, настройки громкости, плавное нарастание и проверка воспроизведения.
